Questions fréquentes

Mes données sont-elles téléversées ?

Non. Budgets stocke les données localement sur votre appareil. Aucun cloud n’est utilisé.

Comment Budgets se synchronise-t-il avec mon appareil partenaire ?

Budgets se synchronise directement d’un appareil à l’autre. Aucune connexion n’est requise.

Puis-je exporter mes données ?

Oui, vous pouvez exporter les données au format CSV.
