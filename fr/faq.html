  <h2>Questions fréquentes</h2>

  <h3>Mes données sont-elles téléversées ?</h3>

  <p>Non. Budgets stocke les données localement sur votre appareil. Aucun cloud n’est utilisé.</p>


  <h3>Comment Budgets se synchronise-t-il avec mon appareil partenaire ?</h3>

  <p>Budgets se synchronise directement d’un appareil à l’autre. Aucune connexion n’est requise.</p>


  <h3>Puis-je exporter mes données ?</h3>

  <p>Oui, vous pouvez exporter les données au format CSV.</p>
