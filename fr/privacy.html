Politique de confidentialité pour « Budgets »

Version en vigueur : 08.02.2026

La protection de vos données est importante pour nous. La présente politique de confidentialité explique comment l’application « Budgets » (ci-après « l’application ») traite vos données.

1. Principe : aucune collecte de données

Nous (le développeur) ne collectons, ne stockons ni ne traitons aucune donnée personnelle sur nos serveurs. Nous n’exploitons aucun serveur propre pour cette application.

2. Stockage local

Toutes les données financières, catégories et préférences sont stockées exclusivement localement sur votre appareil.

3. Synchronisation (Multipeer Connectivity)

L’application propose une fonction de synchronisation entre appareils proches.

  • Cela s’effectue via le framework Multipeer Connectivity d’Apple.
  • Les données sont transférées directement d’un appareil à l’autre via le Wi-Fi ou le Bluetooth.
  • Les données ne quittent pas votre réseau local et ne sont pas envoyées sur Internet vers des serveurs externes.

4. Achats intégrés

Le traitement des achats (par ex. « version complète ») s’effectue exclusivement via l’App Store d’Apple (StoreKit).

  • Nous recevons uniquement d’Apple une confirmation anonymisée indiquant si l’achat a réussi.
  • Nous n’avons pas accès à vos données de paiement, à votre nom ni à votre adresse de facturation.

5. Contact

Pour toute question ou remarque, vous pouvez nous contacter à l’adresse budgetsapp@larsmalte.com.
